# 🎓 Student Marks Prediction using Machine Learning

## 📌 Overview

This project predicts student exam marks based on the number of study hours using a Linear Regression model.

An interactive Streamlit web application allows users to enter study hours and instantly view the predicted marks.

---

## 🚀 Features

- Predict student marks using Linear Regression
- Interactive Streamlit web application
- Data visualization with regression line
- Model evaluation using MAE and R² Score
- Clean and organized project structure

---

## 🛠 Technologies Used

- Python
- Pandas
- NumPy

- Scikit-learn

- Streamlit

## ▶️ Run the Project

Clone the repository

```bash

```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the application

```bash
streamlit run app.py
```
